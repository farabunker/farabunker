Model sets

A model in no set is usable by everyone who may use its capability. Putting it in a set narrows it to the people who hold an entitlement attached to that set — a set with no entitlement attached narrows nothing — and makes it unreachable from the watcher and the command line, which hold none. Models bound to a role — embeddings, transcription, extraction, and the default answering model — are never narrowed: that is how ingestion keeps working for the whole box.
