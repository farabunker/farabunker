Agent access

An agent or a flow with no entitlement is runnable by everyone signed in. Labelling one narrows it to the people who hold any of its entitlements.

A labelled agent or flow is unavailable to the watcher and the command line, and that includes the ones this platform ships — automated callers hold no entitlements, so manage.py agent_turn simply cannot run it. A label also applies to the account that created the agent: if they do not hold one of its entitlements they can no longer run it, though the conversations they already started stay readable.
