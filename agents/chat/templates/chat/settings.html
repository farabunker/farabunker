{% comment %} WHAT THE TOGGLE ACTUALLY DOES, both halves of it, in the operator's terms -- not "time awareness" as a word that could mean anything. The zone is this box's own configured zone, stated so nobody has to guess whose clock the model is being handed. {% endcomment %}

On by default. Adds one line to every conversation's prompt naming the current day, date, time and UTC offset from this box's own clock, and stamps each earlier message in the conversation with when it was sent. Without it a model falls back on whatever its training implies "now" is, and can report the current year as a set of future dates. Turning it off removes both the date line and the message stamps. Delegated agents get the date line too. The clock reads in this box's configured time zone — UTC unless FARABUNKER_TIME_ZONE is set in the environment.
